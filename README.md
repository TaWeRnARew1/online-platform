# Онлайн-платформа — Калалб Дмитро Олександрович

Індикатор 1.10: **Рентабельність операційної діяльності підприємств будівництва**.

## Публікація через GitHub Pages
1. Створіть новий публічний репозиторій, наприклад `economic-security-1-10`.
2. Завантажте файл `index.html` у корінь репозиторію.
3. Відкрийте **Settings → Pages**.
4. У **Build and deployment** виберіть **Deploy from a branch**.
5. Branch: `main`, папка: `/ (root)`.
6. Натисніть Save.
7. Через кілька хвилин GitHub надасть адресу виду:
   `https://ВАШ-ЛОГІН.github.io/economic-security-1-10/`

## Методична база
Наказ Міністерства економічного розвитку і торгівлі України від 29.10.2013 №1277.
Для індикатора 1.10 характеристичні значення: -1, 3, 4, 5, 6, 10, 20, 30, 40, 60%.
Індикатор є змішаного типу; оптимальна зона — 6–10%.

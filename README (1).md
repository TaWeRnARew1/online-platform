# Онлайн-платформа для оцінювання рівня економічної безпеки держави

## Індикатор 1.10

**Назва:** Рентабельність операційної діяльності підприємств будівництва, %.

**Виконавець:** Калалб Дмитро Олександрович.

Цей міні-сайт призначений для інтерактивного оцінювання стану виробничої безпеки за одним конкретним індикатором - рентабельністю операційної діяльності підприємств будівництва.

## Методична база

Платформа побудована за **Методичними рекомендаціями щодо розрахунку рівня економічної безпеки України**, затвердженими наказом Міністерства економічного розвитку і торгівлі України від **29.10.2013 № 1277**.

У Методичних рекомендаціях індикатор 1.10 визначений як:

> Рентабельність операційної діяльності підприємств будівництва, відсотків.

Для нього наведені характеристичні значення:

**-1; 3; 4; 5; 6; 10; 20; 30; 40; 60 %.**

Індикатор належить до **змішаного типу A**: до оптимального значення підвищення показника покращує оцінку безпеки, а після проходження оптимального інтервалу подальше зростання погіршує її. В оптимальному інтервалі **6-10 %** нормоване значення дорівнює **1 (100 %)**.

Рівні нормованої оцінки за методикою:

| Рівень | Нормоване значення |
|---|---:|
| Критичний | 0-0,2 |
| Небезпечний | 0,2-0,4 |
| Незадовільний | 0,4-0,6 |
| Задовільний | 0,6-0,8 |
| Оптимальний | 0,8-1,0 |

### Нормування

Платформа реалізує лінійне нормування між сусідніми характеристичними значеннями. Для змішаного індикатора:

- **-1-3 %:** нормоване значення зростає від 0 до 0,2;
- **3-4 %:** від 0,2 до 0,4;
- **4-5 %:** від 0,4 до 0,6;
- **5-6 %:** від 0,6 до 0,8;
- **6-10 %:** 1,0;
- **10-20 %:** від 1,0 до 0,8;
- **20-30 %:** від 0,8 до 0,6;
- **30-40 %:** від 0,6 до 0,4;
- **40-60 %:** від 0,4 до 0,2;
- за межами крайніх значень **-1 % і 60 %** нормоване значення дорівнює 0.

## Джерело вхідних даних

Для індикатора 1.10 Методичні рекомендації не задають окремого арифметичного розрахунку: у таблиці джерел вхідної інформації вказано статистичний показник **«Рентабельність операційної діяльності підприємств за видами економічної діяльності»**, Держстат.

Тому користувач вводить готове статистичне значення рентабельності за кожний рік, а платформа виконує його нормування та оцінювання.

## Що вміє платформа

1. Приймає дані за одним або кількома роками.
2. Перевіряє коректність року та числового значення рентабельності.
3. Не дозволяє вводити дублікати років.
4. Розраховує нормоване значення показника.
5. Визначає рівень економічної безпеки для кожного року.
6. Розраховує середню рентабельність за введений період.
7. Розраховує середнє нормоване значення за введений період.
8. Формує підсумкову таблицю.
9. Автоматично створює короткий аналітичний висновок.
10. Містить пояснення одиниць вимірювання, характеристичних значень та алгоритму оцінювання.

## Структура проєкту

```text
index.html        - основний файл інтерактивної платформи
README.md         - документація проєкту
```

Платформа не потребує серверної частини або бази даних: усі розрахунки виконуються безпосередньо у браузері за допомогою JavaScript.

## Публікація через GitHub Pages

Для розміщення сайту в Інтернеті достатньо завантажити `index.html` у корінь репозиторію GitHub та увімкнути **Settings -> Pages -> Deploy from a branch -> main -> /(root)**.

Після публікації GitHub Pages сформує веб-адресу виду:

```text
https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/
```
